## Project name
Incident Brief

## Elevator pitch
Turn a small log excerpt into a local incident brief with grouped events, source-line evidence and Markdown export.

## About the project
Incident Brief helps a system administrator prepare an incident handoff from a small application-log excerpt. It groups repeated events, preserves source-line evidence, masks common sensitive patterns and exports a Markdown brief. The input stays in the browser; no inference model runs on the logs.

The proof of concept was built with AI coding assistance and the official Devpost Learn Skill Pack, using scope, PRD and technical-spec documents. The participant chose a solo, eight-hour limit, delegated the narrow scenario and implementation, and accepted the local preview.

The technical challenge was to group repeated messages without losing evidence or merging different HTTP status codes, and to handle incomplete private-key blocks. Tests cover these cases and the local HTTP boundary. Redaction is best-effort and exported reports need manual review; the tool does not establish a root cause.

## Built with
