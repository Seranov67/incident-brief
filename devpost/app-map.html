REFERENCE ROUTE · NOT A RECORD OF LEARNER PRACTICE

One action, three places.

Incident Brief turns a pasted log into grouped, sanitized evidence and a Markdown handoff. No upload endpoint or inference service.

Paste / analyzeRecognize · redact · groupRead / download

Follow the action

  1. public/app.js — the Analyze button calls analyzeLog with the editor's current text.
  2. public/analyzer.js — redact masks supported patterns; analyzeLog tracks source lines and groups severity plus normalized message.
  3. public/app.js — render uses textContent; the download handler calls toMarkdown on the current snapshot.

To change this, start here

A masking pattern

Edit redact, then add a case in test/analyzer.test.js. Test both that the secret disappears and that source-line numbers remain correct.

Grouping or diagnostic suggestions

Edit normalize / nextCheck. Preserve distinct HTTP status codes; variable request IDs and durations may group.

Layout or wording

Use public/styles.css and public/index.html. Log-derived strings remain DOM text, never HTML.

A practice to reuse

A concrete counterexample improves a vague requirement. Grouping every number also merged HTTP404 and HTTP500. A regression case now keeps these distinct while allowing varying timeout durations to group. See the status-code test in test/analyzer.test.js.
