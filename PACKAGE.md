## Required form fields
Overview: name and pitch. Details: About, Built with, source URL and hosted demo URL.
Additional info: individual/team, residence, resources actually used, AI-cost effect, current confidence, license URL, value category and explanation of Learn Skill Pack use. Personal exit-survey answers are kept outside this public repository.

## Known limits
Plain uppercase log levels or JSONL, at most 200 KiB / 2,000 non-empty lines; top eight groups. Pattern observations are not a diagnosis. Best-effort redaction can miss secrets.
